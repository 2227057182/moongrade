# MoonGrade 项目申报书

## 项目名称

MoonGrade：MoonBit 作业评测与学习反馈平台

## 项目方向

开发工具与 AI 时代学习基础设施。MoonGrade 面向 MoonBit 课程、训练营、社团、开源入门教程和自学者，把真实项目检查、评分与反馈组织成可复现流程。

## 具体需求

MoonBit 教学和社区任务目前大量依赖人工批改：学生只看到编译或测试输出，教师需要逐个运行仓库、人工汇总成绩，教程示例也缺少统一完成标准。现有工具能运行测试，却很少把作业定义、隐藏检查、部分得分、错误解释、班级汇总和 CI 门禁连成一条工作流。

MoonGrade 补足这一层：教师定义一次作业，所有学生和 CI 使用同一套规则；学生得到明确反馈；教师一次获得全班结果。

## 三个完整使用场景

1. **教师批改课程作业。** 教师配置编译、公开测试和自定义命令，一次扫描多个学生目录，生成个人报告和班级汇总。
2. **学生自查。** 学生运行一条命令，得到当前分数、通过项、失败原因和下一步建议，不必等待人工批改。
3. **社区维护教程。** 开源社区把教程示例变成自动验收练习，在 CI 中阻止损坏的示例或低质量示例合入。

## 核心功能

- JSON 作业清单：检查类型、分值、超时、必过规则和提示。
- 复制学生仓库到临时目录，避免修改原始提交。
- 执行 `moon check`、`moon test` 和显式自定义命令。
- 根据测试通过比例计算部分分，不只看整体成功或失败。
- 将常见编译与测试失败映射为可执行提示。
- 输出 Markdown、JSON、自包含 HTML 报告和班级汇总。
- 通过退出码接入 GitHub Actions 或其他 CI。

## 技术方案

作业解析、校验、评分和报告使用 MoonBit。Node.js 适配层只负责临时目录、子进程和文件系统；命令不经过 shell 拼接，并有超时和输出上限。教师批量模式扫描包含 `moon.mod` 或 `moon.mod.json` 的学生项目，为每位学生生成独立报告。

`examples` 中的通过项目得到 100/100，测试失败项目得到 65/100，编译失败项目得到 0/100，并分别返回确定的退出码，用来证明评分、部分分、反馈和 CI 集成真实工作。

## 原创性与生态定位

Mooncakes 上已有 `moonmentor` 等学习辅助项目，但重点不同：MoonGrade 不尝试替代学习路径或自动讲题，而是完成真实作业的执行、评分、反馈和班级工作流。它不是仅面向单个包的库，而是同时服务教师、学生和社区维护者，能成为 MoonBit 教育生态的公共入口。

## 验收与边界

- MoonBit core 包含作业解析、评分、诊断和报告逻辑。
- 核心库测试在 JS、Wasm 和 Wasm-GC 目标上通过。
- 仓库提供通过、失败两个学生样例和可运行报告。
- 单元测试、端到端评测、格式检查和严格编译检查进入 CI。
- Apache-2.0 开源，README、架构、作业格式和课堂流程完整。

当前版本服务于本地可信作业，不承诺公网恶意代码沙箱。远程提交收集、账号系统和成绩数据库属于后续计划。
